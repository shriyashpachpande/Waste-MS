# Smart Waste Management Platform — Backend

> **Production-ready Node.js/Express+Mongoose API**

## Features

- User registration with admin approval (pending flow)
- Role-based JWT authentication & middleware
- Training modules (video, lesson, MCQ, certificate)
- Waste record lifecycle tracking
- Vehicle GPS endpoints & sample integration
- Citizen reporting and Green Champion workflow
- Shop endpoints (bins, kits)
- Rewards and penalty APIs
- Analytics endpoints (aggregates + ML skeleton)
- Admin/ULB dashboards (API for approve & manage)
- Seeders & Postman collection
